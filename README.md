1. サービス概要
どんなサービスか
「ゆめかわいい」世界観で、欲しいものや叶えたい目標への貯金進捗を楽しく可視化・達成コレクション化できる目標達成サポートアプリ。

誰の、どんな課題を、どう解決するか
「貯金や節約が長続きしない」「高額な目標に向けてどのくらい1日節約すると達成できるのか見通しを立てるのが苦手でいつまで経っても目標を達成できない」「誰かとシェアしてモチベーションを高めたい」と感じる人の課題を、視覚的なワクワク感（ゆめかわUI・進捗バー）、日割り目標の自動計算、プライバシーに配慮した画像ダウンロード機能で解決します。

2. このアイデアはどこから生まれたか
2-1. きっかけとなった体験・感情
欲しいものを買うために貯金をしようと思っても、既存の家計簿アプリや貯金アプリは無機質な数値ばかりでモチベーションが続きませんでした。また、SNSでウイッシュリストを投稿している人が沢山いてそういった投稿を見てモチベーションを上げることを学生の頃からしていたので実際にウイッシュリストのアプリがあるといいなと思いました。ただし、「これ買うために節約頑張る！」と宣言したくても、具体的な金額や生々しい財務状況が写ったカード画像をシェアするのは心理的抵抗があるので画像のみシェアできれば今まで通りウイッシュリストの公開はできて、自分がどのくらい節約をすればいいかわかる機能がついて一石二鳥だと思い、自分自信が一番欲しくて使いたいアプリを作成しました。

2-2. なぜそれが「気になった」のか
自分自身が「目標達成までのプロセス自体も可愛く、テンションの上がる空間で楽しみたい」という価値観を大切にしているからです。単なる「管理作業」ではなく、「ときめく体験」でなければ継続できない性格だと自覚していたため、既存ツールでは満足するものがなく、インストールだけして何も活用できていなかったからです。

3. 課題の整理（表面的になっていないか）
3-1. 表に見えている困りごと
貯金や節約が途中でモチベーション切れになり、目標を達成できない。
具体的にどのくらい1日または1ヶ月に貯めればいいのかわからない。

3-2. 本当に解決したい課題は何か
なぜ途中でやめてしまうのか？ → 毎日の進捗を感じにくく、目標達成までの道のりが遠く感じるから。ときめきがなくて使う気が湧かないから。

なぜ遠く感じるのか？ → 「あと〇〇円」という数字だけでは、今日何をすればいいか実感が湧かないから。

なぜ実感が湧かないのか？ → 自分の生活ペースに落ちた「今日やること（日割り目標）」が見えず、管理作業自体も楽しくないから。

→ 本当に解決したい課題：目標達成までの過程において、日々の小さな前進を「ときめき」とともに実感できず、モチベーションを維持できないこと。

4. 想定ユーザーについて
4-1. 想定しているユーザー
年齢：10代後半から30代前半の女性

理由：推し活、ファッション、美容など「叶えたい・欲しいもの」が明確にあり、SNS的な世界観や可愛いデザインに強く共感しやすいため。

生活・状況：一人暮らしや毎月のやりくりの中で、欲しいもののために少しずつ節約・貯金をしている人

理由：日割りの節約目標（「1日あたり〇〇円」）が見えることで、日々の買い食いや無駄遣いを楽しくセーブできるため。

環境：自分のペースで目標に向かいたいが、SNSでプライベートな金額面を過剰に公開したくない人

理由：金額が入らない「お気に入りの元画像ダウンロード機能」により、プライバシーを守りつつ達成感をSNSで表現できるため。

4-2. 自分とユーザーの距離
自分自身（および過去の自分）
自分自身が感じた「既存ツールの可愛さ不足」や「SNSシェア時のプライバシーへの懸念」がそのまま開発の出発点になっているため。

4-3. 実際に使われる可能性について(需要・存在確認)
最初に使ってくれそうな人：ゆめかわいいデザインや可愛い雑貨・服が好きで、欲しいものに向けて貯金したい友人やSNS上のユーザー。

思い出す瞬間：欲しいものを見つけた時、日々の節約を意識した時、目標を達成して自分を褒めたい時。

代わりに使っているもの：メモ帳アプリ、普通の家計簿アプリ、紙のノート、Xのポスト

置き換えて使う理由：開くだけでテンションが上がる世界観があり、あと何日で1日いくら節約すれば良いかが一目でわかるから。

4-4. ユーザーがサービスを導入して利用するまでのイメージ
きっかけ：SNSやポートフォリオで可愛いデザインを見かけ、「ログイン不要で手軽に試せる」ことから利用開始。

最初の一歩：会員登録の手間なく、欲しいもののタイトル・目標金額・期日・お気に入り画像を登録するだけ。

継続する理由：貯金するたびに進捗バーが伸び、日割りの達成目安が毎日更新されるため、日々の節約がゲーム感覚で楽しくなるから。

5. 既存サービス・競合調査
5-1. 似たサービスの調査
サービス名：一般的な目標貯金アプリ・家計簿アプリ（家計簿マネーフォワード、シンプル家計簿、人生で叶える夢リスト）

どんなことができるか：口座連携やカテゴリ別の収支管理、目標金額に向けた積立計算。夢について管理。

5-2. それでも自分が作りたい理由
既存アプリは「効率的で実用的」ですが、画面が堅苦しく「管理されている感覚」が強くてワクワクしませんでした。また、達成時の画像をシェアしようとすると「目標金額」が大きく印字されたカード画像が出力されるものが多く、「高額な買い物の金額をSNSに出したくない」という心理に寄り添えていない点に不満がありました。夢についてのアプリは漠然としすぎていて使いにくいと個人的には思ってしまうので金銭が発生する実現したいことに絞って作りました。

5-3. 差別化を「体験価値」で表現する
私のアプリの差別化ポイント：
推し活や欲しいものがある人が、ログインの手間なくすぐ始められ、日割りの節約目標とゆめかわUIで「毎日楽しく貯金しながら、達成したお気に入りの写真だけを安全にSNSへ連れ出せる体験」を提供すること。

6. このサービスで提供したい価値
6-1. ユーザーの変化
行動の変化：無駄遣いを減らし、「1日〇〇円節約しよう」と毎日の生活の中で意識して貯金できるようになる。

気持ちの変化：貯金＝我慢という義務感から、貯金＝欲しいものに近づくワクワクする体験へと変わる。

考え方の変化：目標達成までの「過程」そのものを楽しめるようになる。

6-2. 価値を一文で表す
「このサービスは可愛い世界観で欲しいものを管理したい人が、日割りの節約目標とプライバシーに配慮した画像保存で、楽しく安全に目標達成できるようになるサービス」

8. 今後の課題と対応計画
現状の課題:

開発期間の都合上、MVPフェーズではユーザー認証（ログイン機能）の実装を見送り、コア機能（貯金トラッキングやUI表現）の実装を優先しました。そのため、現在は全ユーザーでデータが共有される状態となっています。

今後の対応:

実際の運用・マルチユーザー利用に向けて、Deviseを用いたユーザー識別機能およびゲストログイン機能を速やかに追加実装する予定です。

9. 今後の展開・発展の方向性
今考えている発展案
機能追加の方向性：Deviseによるユーザー管理の導入、ゲストログイン機能の実装。

UI・体験の改善、カラーテーマ切り替え機能

機能以外の工夫：READMEに「なぜログイン機能をMVPで外したのか」の設計思考（意図的なUX判断）を記載し、ポートフォリオとしての評価を高める。

「ゆめかわいい」世界観にこだわったデザインとUI設計
